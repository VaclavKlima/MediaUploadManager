# Series Uploadcomposables

## Auto-start assigned Shows only on their immutable home disk
When a Show has home_disk_id, storage preview must expose only that root and batch preparation may auto-start once per stable review only if it is configured, healthy, and sufficiently spacious. Never offer or select a fallback disk; a failed auto-attempt requires an explicit retry.
